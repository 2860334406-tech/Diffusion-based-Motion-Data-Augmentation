# EXP-022 冻结 Actor：真值与估计接触输入的配对闭环

这一步直接把估计器输出接入 `policy/chest_speed_gradient_v1/policy.pt` 的 Actor：每个 20 ms 控制步计算 930 维历史和 10×29 关节空间力矩历史，估计三维力，再用胸推映射生成 32 维接触历史，替换 Actor 128 维观测的末尾 32 维。其余 96 维、策略权重和推手条件不变。真值组仍使用原接触观测；两组都在后台运行同一个冻结估计器，用于逐帧核对。

## 原始 EXP-022 推手协议

球半径 0.1 m、质量 5 kg，参考速度 0.2 m/s，电机力上限为机器人重量的 0.15 倍；推手按原策略的 `force_done_ratio=0.03` 判定并回撤。此模式下审计文件里的 `target_force_n=30` 是持续推压脚本的占位参数，不控制原推手。固定种子 181–188，各跑真值和估计输入一次，共 16 个仿真回合。策略、prior、估计器和映射均未训练或修改。

| 结果 | 真值输入 | 估计输入 |
| --- | ---: | ---: |
| 推手实际碰到机器人 | 8/8 | 7/8 |
| 原任务 `event_success` | 8/8 | 7/8 |
| 失败终止 | 0/8 | 2/8，均为 `workspace` |
| 连续真实合力 ≥10 N 的最长时长 | 各回合 0.02–0.04 s | 有接触回合 0.02–0.04 s |

有接触的 7 对回合，首次接触发生在同一控制步；接触前最大单关节动作差不超过 0.00066。181 号是例外：物理接触前第 12 步估计出 61.08 N，真值为 0 N，接触概率 0.888。估计输入组的 Actor 接触开关在真实接触前累计打开 51 帧，动作随之改变；该组最终没有碰到球头，`event_success=0`。真值组在第 135 步发生接触并完成事件。估计组另有 183、188 号在事件成功后触发 `workspace` 终止。这里没有把 `workspace` 终止称为摔倒。

[8 组真实力与估计力曲线](original/paired_force_traces.png)以各自真值组首次接触为中心放大时间轴；[181 号误报、Actor 开关和动作差曲线](original/seed181_precontact_feedback.png)展示更早的接触前阶段；[181 号并排视频](original/seed181_oracle_left_estimated_right.mp4)左侧真值输入、右侧估计输入。逐回合指标见 [`per_episode.csv`](original/per_episode.csv)，配对差值见 [`per_pair.csv`](original/per_pair.csv)，条件与汇总见 [`design.json`](original/design.json)、[`summary.json`](original/summary.json)。16 回合共 8,922 个推理帧，用保存的本体输入重放估计器后，三维力各分量最大差为 0 N；估计组 Actor 的 32 维接触历史重放最大差为 2.71×10⁻⁷，真值组 Actor 接触历史与原观测逐项相同，见 [`streaming_replay_audit.json`](original/streaming_replay_audit.json)。录屏与无录屏的 181 号回合接触/终止结论相同。

`event_success` 是原任务的事件判定，不能替代持续受力卸力测试。185 号虽然有 8.24 s 几何接触，≥10 N 受力只持续了 0.08 s；其他回合也只有短促有效加载。因此这 8 对回合验证了闭环接口并暴露误报风险，不能证明估计输入下的持续卸力能力。

## 持续推压压力测试

另用半径 0.1 m 的球头和持续推压导轨，预定 10/20/30/40 N × 1/5 kg 共 8 组，仍成对比较真值与估计输入。该控制器不会像原协议那样在成功后及时回撤。真值组和估计组均 **8/8 失败终止**；真实合力 ≥10 N 的最长连续段分别为 0.06–0.14 s 和 0.02–0.32 s。标称驱动力不等于实际接触力，例如 10 N、1 kg 的真值组峰值为 65.18 N。由此不能把压力测试的失败归因于估计器，也不能据此评价卸力效果。

[压力测试曲线](sustained/paired_force_traces.png)、[逐回合指标](sustained/per_episode.csv)、[配对差值](sustained/per_pair.csv)、[条件](sustained/design.json)和[汇总](sustained/summary.json)保留供复核。一次更轻、更软的 10 N / 0.2 kg / `solref=0.1 s` 真值试跑仍在 0.20 s 连续有效加载后因自碰撞终止；181 号零电机推力对照则在两种输入下均无物理接触，12 s 无失败终止。后者说明误报会改变动作和接触机会，单独的误报未在该对照中造成失败。

## 下一步

先用独立开发种子补足运动起始阶段的零力难负例，针对接触前单帧尖峰与反馈放大重新设计门控；冻结后再用新种子重复配对闭环。持续卸力实验还需先找到真值输入组能够稳定承受至少 1 s、实际合力保持在目标范围的物理推手条件，再比较估计输入。当前不进入 PPO 微调或联合迭代。

原始每步观测、接触几何、力曲线和录屏另存于本地移动硬盘归档；仓库内保留可复核的配置、汇总、逐回合数据、图和视频。仿真结果不代表真实 G1 硬件表现。
