# EXP-022 持续球头三路闭环：估计器峰值漏检

沿用冻结的 EXP-022 Actor、prior、V1 力估计器和胸推输入映射。三路只改变 Actor 收到的接触输入：遮蔽、真值、估计；物理球头和随机种子逐组相同。遮蔽组用于检查球头能否持续加载，真值与估计组用于比较闭环行为。球头半径 0.1 m、质量 5 kg、目标推力 20 N、参考速度 0.06 m/s，导轨电机持续施力；真值是 MuJoCo 每个 20 ms 控制步的三维实际接触合力，不是目标推力。

## 冻结新种子 205–212

参数、8 个种子和严格有效对照条件在运行前写入 [条件清单](three_arm_frozen_pretest.json)：遮蔽组躯干真实合力连续 ≥10 N 至少 1 秒、峰值 ≤80 N，且整回合无失败。三个输入组共 24 回合，所有失败均保留。接触前轨迹最大差在 0.0000033 m 内，三路首次物理接触步逐组一致。GPU 为本地 RTX 4060，每个进程最高记录 354 MiB；未占用远端 A100。

严格有效对照只有 **211 号 1/8**：遮蔽组持续加载 7.02 s、实际峰值 31.7 N、无失败。该种子的前 1 秒真实力冲量为遮蔽 16.92、真值 5.38、估计 4.97 N·s；但真值和估计组随后分别达到 123.2、120.4 N 峰值并失败。其余遮蔽组常在前几秒持续加载，最终多因 `workspace` 终止，未通过预先冻结的整回合门槛。不能把 8 组冲量中位数当作通过质量门槛的卸力成功率，也不能把 `workspace` 直接称为摔倒。

估计输入组的 **8/8 个真实力峰值帧输出均为 0 N**；峰值帧均涉及右肩或右肘碰撞几何，实际峰值为 35.7–129.8 N。估计器在这些帧的接触概率为约 1.7×10⁻¹¹–0.041，门槛 0.6 将力置零。8 个估计闭环回合的 ≥10 N 受力帧，逐回合三维向量 MAE 中位数约 22.7 N；4/8 回合首次 ≥10 N 帧未激活 Actor 的估计接触输入。方向角只对已检出的非零估计有定义，不能用其掩盖峰值漏检。此次各组接触前 Actor 误触发为 0；峰值漏检是新的主要问题。

## 受控改进检查

此前尝试只在“估计力 >40 N 且接触概率 <0.95”时抑制接触前尖峰。旧 181 号回合可被抑制，但规则冻结后的新种子 197–204 共 24 回合中**一次也未触发**，真值组还有 1/8 未接触，预设质量条件未过。此规则未接入冻结 V1，详见[冻结条件](guard_frozen_pretest.json)和[新种子结果](guard_locked_summary.json)。

针对运动中的右肩接触迁移，又用 205–208 的真值与估计闭环轨迹补训练数据，209–212 加旧验证集选单一 V1 特征架构的权重，保留原阈值 0.6 与 10 帧预热。增大新数据权重到 8 后，新运动验证集的逐回合三维向量 MAE 中位数从 16.88 降到 13.53 N，峰值低于 10 N 的漏检由 4/8 降到 1/8；但旧验证集 MAE 从 7.99 升到 8.32 N，零力 ≥10 N 误报由 38 增到 58 帧，首次受力漏检由 8 增到 10 回合。这个候选**未发布、未替换 V1、未进入 PPO**。[候选对照](motion_candidate_selection.json)记录三个新数据权重的结果；所有候选均只做了离线验证，没有独立新种子的闭环验收。

## 当前结论与下一步

球头能在遮蔽输入下形成持续物理接触；真值与估计输入都能使初期接触力下降，但冻结策略在这批持续施力回合中不稳定。估计器还会在右肩/右肘接触迁移时把高峰值判为无接触。下一步应先补足这些接触迁移与零力难负例的完整轨迹，按独立回合验证峰值漏检、接触前误报、首次接触和旧场景退化；只有估计器达到条件后，再按 EXP-022 主线做真值到估计输入的 PPO 微调。以上全是仿真证据，不代表真实 G1。
