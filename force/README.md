# G1 力估计器交接

这里存放供 `integration/force` 分支加载和核对的冻结力估计器。每个版本独立归档权重、归一化、评估结果、清单和说明，接口代码位于 `src/smp/force_estimation/`。

| 版本 | 用途 | 当前状态 |
| --- | --- | --- |
| [v392](v392/README.md) | 站立 G1、球头导轨接触的三维合力估计；包含 V3.57、V3.82、V3.92 三档输出 | 仓库内加载和保存轨迹重放已验证；尚未接入 SMP 策略观测 |

`force/v392/` 中的权重以原始字节复制，`manifest.json` 和 `SHA256SUMS` 记录 SHA-256。训练数据、缓存和视频保留在实验存储，不放进 Git 仓库。新增版本请另建目录，保留这个版本的权重身份和评估记录。

目前的 `policy/chest_speed_gradient_v1/` 策略使用 8 维接触观测。力估计器给出 `torso_link` 坐标系的三维合力；策略需要的是 heading 坐标系、按机器人重量归一化的滤波接触量。两者转换和在线时序校验属于下一阶段，本次交接只提供可加载模型和显式输入接口。
