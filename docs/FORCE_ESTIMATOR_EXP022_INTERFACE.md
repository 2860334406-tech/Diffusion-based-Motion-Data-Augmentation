# EXP-022 力估计器接口对齐

本文件记录 `policy/chest_speed_gradient_v1/` 与冻结 V3.92 力估计器之间的**数据接口**。适配代码在 `src/smp/force_estimation/exp022_interface.py`。当前工作没有修改 EXP-022 策略、奖励或球头环境，也没有用估计力跑策略评估或继续 PPO。

## 输入：从 SMP 仿真构造 SuperMimic 观测

在创建 mjlab 环境之前调用 `add_force_estimator_observations(env_cfg)`。它另外注册两个观测组，不改变原 Actor 的 128 维输入和 Critic 的 992 维输入：

| 观测组 | 形状 | 取值与顺序 |
| --- | --- | --- |
| `force_estimator_x` | `(B, 930)` | 10 帧，从旧到新；依次为相对默认姿态的**带编码器偏置**关节角 290 维、关节角速度 290 维、root 坐标机体角速度 30 维、投影重力 30 维、原始上一动作 290 维。按观测项连续排列。 |
| `force_estimator_tau` | `(B, 10, 29)` | 同样从旧到新的帧末 `qfrc_actuator`，按 G1 关节自由度排列；不是 motor-space `actuator_force`，也不是球头推力。 |

这里刻意使用原 SuperMimic 的 `joint_pos_rel(biased=True)` 和 `base_ang_vel`。SMP Actor 自身的关节角观测没有 `biased=True`，角速度来自 IMU 传感器，不能从它的 128 维输入直接切片得到估计器输入。两个任务都使用 G1 的 29 关节和同一 `G1_ACTION_SCALE`，但适配器仍在运行时核对**关节顺序和动作顺序**。mjlab 历史缓存按回合重置，对第一帧回填，随后按 20 ms 控制步推进；`validate_force_estimator_input` 检查维度和有限值。

输入观测在推理时关闭随机噪声。原估计器训练数据曾加入 SuperMimic 观测噪声；这一分布差异需在旁路评估中单独检查。若要从原始机器人传感器部署，还需重新核实执行器力矩是否可测、延迟及时间对齐。

## 输出：转换成 EXP-022 接触观测

`Exp022ContactAdapter` 每个 20 ms 控制步接收估计器的 `force_body_n`、`point_body_m` 和**当前步结束时**的躯干、root 位姿。冻结估计器的三维力与点都在 `torso_link` 坐标系。转换顺序如下：

1. 用 `torso_link` 四元数把三维力转至世界系，再用 root 的 yaw 四元数转至 heading 局部系，归一化得到方向。
2. 把躯干坐标中的作用点转至世界系，减去 root 位置，再转至 heading 局部系。
3. 以估计三维**合力模长**作为标量力，按 EXP-022 的 `EMA = 0.8 × 上一步 + 0.2 × 当前值` 滤波；以 `0.0075 × 机器人重量` 为接触开关阈值。接触时力标量除以机器人重量并截断到 `0.4`，无接触时 8 维全为零。
4. 按 mjlab 相同的旧到新顺序组成 4 帧、共 32 维接触历史；回合重置时清空滤波和历史。若瞬时力归零而 EMA 尚未低于阈值，暂时保留上一有效方向和位置，与原控制器相同。

**力标量尚不能声称数值等价。**EXP-022 真值输入是接触点法向力绝对值求和，并对四个 5 ms 子步取均值；V3.92 输出的是 20 ms 内三维接触力的平均合力。多个接触法向不一致、存在切向力，或子步内接触快速变化时，`|平均合力|` 不等于 `平均法向力之和`。V3.92 的 `contact_probability` 不参与原 EXP-022 接触开关；当前转换保持原策略的 EMA 阈值规则。力方向的符号、作用点定义与球头真实碰撞的吻合程度需要在旁路对照中验证。

## 当前边界与下一步

本次完成的是**接口构造和 CPU 检查**。4 个单元测试通过；另用 1 个 CPU 环境确认 Actor 仍为 128 维、Critic 仍为 992 维、新组为 `(1,930)` 与 `(1,10,29)`，并把新组实际送入 V3.92 做了一次有限值推理。可复现的接口检查命令如下；脚本移除 GSI 事件，不推进策略回合，不报告估计精度：

```bash
MUJOCO_GL=disable uv run --locked --extra force-estimator python scripts/smoke_exp022_force_interface.py
```

冻结推理器现在仍是单回合 `step(x, tau_hist, target_site_id)` API；尚未接入 EXP-022 的 Actor/Critic，也未实现大规模并行环境的模型推理。EXP-022 使用 5 kg 球头，现有估计器训练用 1 kg 球头，属于待测分布差异。

下一步是在策略继续使用原接触观测时，旁路收集同一回合的真实接触与估计结果，先确认接线和时序，再评估误报、首次接触、峰值、方向、作用位置及最差回合。只有这些检查完成，才决定更新估计器还是用估计观测继续 PPO。
