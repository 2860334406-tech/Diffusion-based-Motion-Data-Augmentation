## 用途与状态

- 实验编号、任务和训练阶段：待填写。
- 用途：待填写，例如接口联调、评估或继续 PPO 训练。
- 验收情况与已知限制：待填写。候选、未通过或尚未评估的模型应明确标注。
- 实际训练代码版本及未提交改动的冻结快照：待填写。
- 已核对兼容的运行代码 commit：待填写。

## 文件对应关系

| 包内文件 | 原始文件或来源 | 说明 |
| --- | --- | --- |
| `policy.pt` | 待填写原始 run、checkpoint 名称及迭代数 | 保留所需的 PPO 与观测归一化状态。 |
| `prior.pt` | 待填写 prior 名称及 epoch | 说明特征归一化统计是否内置。 |
| `calibration.pt`（如需） | 待填写 | 写明匹配的 prior、归一化及条件 schema；无需时将清单项设为 `null`。 |

| `evaluation.json` | 待填写评估来源 | 评估必须对应这里的 checkpoint 和任务条件。 |

## 归一化与力接口

- Actor 观测归一化：待填写从 checkpoint 中恢复的方式，或独立统计文件及其校验值。
- SMP 特征归一化：待填写来源，确保与 prior 使用同一套统计。
- 力的物理含义、单位和正负方向：待填写。
- 方向与作用点的坐标系、观测字段及顺序：待填写。
- 控制周期、观测历史长度、滤波/延迟及无接触处理：待填写。
- Actor 的观测/动作维度和网络结构：待填写，说明联合分支是否需要做权重迁移。
